Placement test simulation

"You answer a few questions and the test finds your map: where you are lacking."

That is the idea. The output is a mastery map over the concept graph of one CS 156 topic, kernel methods (9 concepts). Each concept gets a probability that you know it, and a ring marks the start point: the first concept to learn next. This page shows how the map is made, how we tested the method on simulated students, and what those tests show and do not show.

TL;DR

A short test that returns a map, tested only in simulation

  1. The method. The test keeps a belief over all 512 sets of the 9 concepts. Each answer updates the whole belief. The output is a map (green ≥ 0.8 knows, yellow 0.4-0.8 partly, red < 0.4 missing) and a start point.
  2. The graph is used twice. It makes prerequisite-closed sets more likely before the first answer (160 of 512 sets), and it defines the start point: a concept you lack whose prerequisites you know, earliest lecture first.
  3. It is a standard method, a cognitive-diagnosis adaptive test (CD-CAT) with the DINA model and a hierarchy-informed prior. It is not our contribution.
  4. Results, simulation only (2,000 simulated students × 25 replications per condition). After 12 items the start point was right in 0.45-0.78 of cases with the audited graph in the base scenario, depending on item noise and parameter error.
  5. Mixed findings. The audited graph beat no graph by 0.04-0.06 only when the simulated students follow that graph. With elicited item parameters the adaptive test did not beat a fixed lecture-order test. The q ≥ 0.8 stop rule was over-confident: 22-56% of confident stops were wrong.
  6. Try it in Watch the test: follow a simulated student step by step, or answer the questions yourself.

The output

Your mastery map, and how the graph is used

The map is what a cognitive-diagnosis computerized adaptive test (CD-CAT) gives. The hidden quantity is not one score. It is the set of concepts you know. After each answer, the test computes for each concept the probability that it is in your set (its posterior marginal). The colours are fixed bands:

green: p ≥ 0.8, knows yellow: 0.4 ≤ p < 0.8, partly red: p < 0.4, missing ring: the start point

The concept graph (prerequisite edges between the 9 concepts) enters in exactly two places:

(a) The prior over sets

Before any answer, the test gives most of the probability to prerequisite-closed sets: if a set holds a concept, it holds that concept's prerequisites. With the 5 audited edges, 160 of the 512 sets are closed. A small mixture weight ε = 0.02 is spread over all 512 sets, so every set stays possible and answers can overrule the graph.

(b) The start-point rule

The start point is a concept on your outer fringe: you do not know it, but you know all its prerequisites. If several concepts qualify, the earliest in lecture order wins. The test reports the most probable start point and its probability q.

The graph does not change the response model or the item choice rule. Two other parts use it only through the prior: which question is asked next, and when the test stops.

Level 1for a student

The story: from one score to a map

  1. Problem: a classic adaptive test gives one ability score. One number cannot say where you should start. Next idea: make the hidden state a set of known concepts. Fix: 9 concepts give 29 = 512 possible sets, few enough to compute exactly.
  2. Problem: 512 sets and only about 12 questions. Next idea: students rarely know a concept without its prerequisites. Fix: a prior that puts most mass on the 160 closed sets (see the grid).
  3. Problem: answers are noisy. People slip on things they know and guess on things they do not. Fix: the DINA response model with a slip and a guess per item (worked example).
  4. Problem: which question next? Fix: ask the item that is expected to shrink the uncertainty over the 512 sets most (Shannon entropy, SHE). At most 2 items per concept.
  5. Problem: when to stop? Fix: stop when the start point is confident (q ≥ 0.8) after at least 4 items, or after 12 items.
  6. Problem: we have no real students to check it. Fix: a simulation study with known hidden states (simulated students), many conditions (explained here) and confidence intervals. It measures how the method behaves under stated assumptions; it cannot show that it works for real students.
Inside the simulation

What a simulated student is

A simulated student has a hidden true set of known concepts. The test never sees it; we use it only to score the test. The base generator (G1) has three steps:

  1. Progress: draw a point in lecture order; the student knows every concept before it.
  2. Random flips: each concept flips (known ↔ unknown) with probability 0.15, so students are not perfect lecture followers.
  3. Closed downwards: drop every known concept whose prerequisites are not all known, until the set is closed under the graph.

Then the student answers each item with the response model below: with a slip probability if they know every tagged concept, with a guess probability otherwise. Answers are drawn once per item, so every arm of the study sees the same student and the same answers.

The generator is not the test's prior: the test assumes a uniform prior over closed sets, while the students come from this progress model. That mismatch is deliberate and realistic.

Inside the test

The DINA model: slip and guess

DINA ("deterministic input, noisy and-gate") is a conjunctive rule. An item tags one or more concepts. If the student knows all of them, they answer correctly with probability 1 − slip. If any is missing, they can still be right by a guess.

Results · simulation-conditional

Is the stop rule's confidence honest?

The test stops when q ≥ 0.8 after at least 4 items. If q were calibrated, at most 20% of those confident stops would have a wrong start point. The false-confidence rate (FCR) is the share of confident stops that were wrong.

The edge audit: which edges survived

Two language models rated each of 11 proposed instructional edges with one question: does mastering the target require mastering the source? Rater 1 (Claude) also proposed the graph; rater 2 (Codex) was blind to rater 1. An edge was kept only if both said yes. One edge outside the proposal (inner products → linear models) came from a sample of 8 non-edges; rater 1 said yes to it after seeing Codex's answer, so that rating is not blind.

Solid amber: the 5 kept edges, used by the test. Dashed: proposed edges that were dropped. Model ratings, not human ratings: agreement on the 11 proposed edges 0.45, κ = 0.18. Every edge still needs human review.

Honesty

What it claims, and what it does not

Claims (simulation pilot only)

  • Conditional operating characteristics: how often the start point is right, under stated assumptions about learners and items.
  • In simulation, the procedure is sensitive to whether its structure matches the learners: structure helps when it matches them.
  • The q ≥ 0.8 stop rule was over-confident in every condition we ran.
  • The two model raters kept few edges as mastery implications (model judgment, κ = 0.18).

Does not claim

  • Validity for real CS 156 students, calibrated items, or any learning gain.
  • That the audited edges are a valid mastery structure. The audited graph both defines the target (the start point) and generates the G1 students, so G1 results are circular as evidence that the graph is right.
  • That the adaptive test beats a fixed lecture-order test with uncalibrated items.
  • That EIG on the start point is the best selection rule.
  • That q is the probability of being right. The app shows q with the stop reason and the label "prototype, not calibrated".
Level 2academic, with sources

Where the method sits

LiteratureA placement test is classification into latent states, not estimation of one trait. Cognitive diagnosis models this directly: DINA is a conjunctive latent-class model with one slip and one guess per item (Junker & Sijtsma 2001). CD-CAT selects items adaptively for such models (Cheng 2009, which also introduced PWKL); Shannon-entropy selection goes back to Xu, Chang & Douglas (2003); GDI is from Kaplan, de la Torre & Barrada (2015); nonparametric selection (Chang, Chiu & Tsai 2019) needs no calibrated parameters.
LiteratureAn attribute hierarchy restricts the permissible attribute patterns (Leighton, Gierl & Hunka 2004). Knowledge space theory reaches the same place from the other side: feasible knowledge states closed under prerequisites (Doignon & Falmagne 1985; Falmagne & Doignon 2011), with slip and guess in the basic local independence model; a DINA model on a hierarchy equals a competence-based BLIM (Heller et al. 2015). ALEKS is the deployed instance (Cosyn et al. 2021).
LiteratureThe q ≥ ρ stop is a Tatsuoka-type rule (Tatsuoka 2002) applied to a function of the state. Such rules become unstable as attributes grow, and a posterior-entropy rule is recommended instead (Guo & Zheng 2019); plug-in parameter errors shorten tests and inflate confidence (Sun et al. 2020). The study follows the ADEMP structure for simulation studies (Morris, White & Crowther 2019).
OursBecause ε = 0.02 gives every subset positive prior mass, the exact name is a saturated DINA CD-CAT with a hierarchy-informed prior. The start point is computed from the posterior restricted to closed sets; the mass outside them (V) is reported, and above V = 0.3 the test gives no start point ("the map does not fit this learner"). "I don't know" is scored as a wrong answer with the same slip and guess.
Level 3our thesis choice

A bounded simulation pilot, not a thesis claim

The placement test is Stage B of the thesis: a second use of the course graph, beside retrieval. It runs in parallel with the main claim and never blocks it. The results may enter the thesis only as a bounded simulation pilot in the future-work chapter, with three points: the model raters kept few mastery edges; the procedure is sensitive to whether its structure matches the learners; the confidence was miscalibrated. All three are conditional on the generators.
