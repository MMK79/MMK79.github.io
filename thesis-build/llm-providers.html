LLM providers: which models, where, at what price

One table of every model we can call through four providers (OpenRouter, AvalAI, ArvanCloud, Alibaba Cloud), with its price in USD and in the provider's own currency. It answers: which model do we use for each job in the thesis pipeline, and what does it cost?

ProblemThe thesis pipeline sends millions of tokens to language models: extraction, answers, judging. Each provider has its own model names, prices, currency and limits.
Why it is hardFrom Iran, not every provider can be paid or reached. Prices change, one Rial rate is only an approximation, and a cheap model may be tier-locked or rate-limited.
FixRead all four price lists on one date, convert them to USD with a dated rate, and pick the cheapest usable model per role. Pilots then test quality.
Prices are not live. This page shows a snapshot read on the dates below. Check the provider before you spend.

    How to read this

    • Blended USD = (3 × input + output) / 4 per 1M tokens, the same rule as the cheapest --role tool.
    • Native price is what the provider lists (Rial for ArvanCloud). USD is converted with the dated rate above; it is an approximation for ArvanCloud.
    • Alibaba prices are the lowest input-length tier; DeepSeek has busy and idle hours. See the notes column.
    • ArvanCloud audio models are priced per minute: the USD columns cover tokens only.
    • Available = no for tier-locked or inactive models. Free (OpenRouter :free) models are hidden by default: 50 requests per day.
    • Proven = read from the provider on the date shown. Inferred or unverified items are marked in the text.

    Data: vault file data/llm-providers.json, read at build time; account balances and keys are never published. Persian text is a machine draft, not reviewed.
